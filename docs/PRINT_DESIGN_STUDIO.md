# PRINT DESIGN STUDIO — V6.0 (المرحلة الأولى)

الصفحة: `/print-studio` (القائمة: PRINT DESIGN STUDIO). منفصلة عن إعلانات المطبعة وعن EDUCATION MASTER.

## سير العمل
REQUEST → PRODUCT ANALYSIS → CREATIVE CONCEPT → ASSET GENERATION → LAYOUT → PREVIEW → USER REVIEW → (اعتماد) → PREPRESS → QA → EXPORT → (إعلان من النسخة المعتمدة فقط)

1. **تصميم جديد**: نوع المنتج ← نشاط العميل ← المقاس ← اللغة/الجهات ← النصوص (من العميل فقط) ← الخامة وشروط الاستخدام ← نوع المخرجات ← «إنشاء تصميم احترافي». التحليل يظهر مباشرة (افتراضات، تنبيهات، ما يمنع الإنتاج) مع ثلاثة اتجاهات إبداعية مقيّمة.
2. **محرر الجهات**: معاينة كل وجه/لوح مع أدلة القص والأمان والطي والمناطق المخفية، تغيير الاتجاه A/B/C، صورة الذكاء الاصطناعي (التكلفة قبل الإنشاء)، رفع شعار العميل الأصلي، تعديل النصوص، تراجع، **اعتماد**.
3. **ما قبل الطباعة / الجودة / التصدير / المعاينة الواقعية / الإعلان / السجل**.

## ما يعمل فعليًا
- **قاعدة منتجات مركزية** (`src/lib/print/catalog.ts`): 11 فئة وأكثر من 100 منتج، كل منتج ينتمي لعائلة (بطاقات، ورقيات، مطويات، متعدد الصفحات، لوحات كبيرة، استيكرات، ملصقات، تغليف، أسطوانيات، ملابس، هدايا، أختام) لها النزيف والأمان والدقة والمتطلبات والطبقات والقواعد. القيم نقاط بداية شائعة — **ليست معايير إلزامية**.
- **إمكانات المطبعة** (الكتالوج ← «تحديد إمكانات المطبعة»): تعطيل المنتجات والخامات والتشطيبات وطرق الطباعة غير المتوفرة؛ لا يقترحها النظام أبدًا. PDF/X المطلوب وملف ICC.
- **فهم الطلب** (`brief.ts`): المنتج والمقاس والهاتف والبريد من النص الحر، الخامة المناسبة للاستخدام (خارجي/ماء/غذاء)، الدقة حسب مسافة المشاهدة، الصفحات بمضاعفات 4، والمتطلبات الناقصة ← **معاينة فقط**.
- **الهوية حسب النشاط** (`identity.ts`): 13 نشاطًا (مطعم فاخر، مطعم ومقهى، طبي، عقاري، ألعاب، عطور، مدرسة، تجميل، سيارات، تقنية، مناسبات، رمضان والعيد، تجارة) بألوان وخط وأسلوب وتصوير وتشطيبات مختلفة.
- **ثلاثة اتجاهات** (`concepts.ts`): فاخر وبسيط / إبداعي وجريء / متخصص في النشاط، بتقييم الارتباط والجمهور والجاذبية والوضوح وسهولة الإنتاج وتكلفة التشطيب.
- **محرك التصميم** (`render.ts`): مقاسات حقيقية بالمليمتر؛ بطاقات بوجهين، مطوية ثلاثية (اللوح الداخلي أضيق 2 مم) وخطوط طي، غلاف كتاب مفرود بكعب محسوب + قوالب الصفحات الداخلية، رول أب بمنطقة قاعدة مخفية وعنوان بحجم مسافة المشاهدة، بنرات بمنطقة العيون، استيكرات بمسار قص Vector ونزيف حول القص وورقة Kiss-Cut (3 مم بين القطع)، شفاف بقناع حبر أبيض، أكواب بمنطقة طباعة ومنطقتي المقبض ونسخة معكوسة، ملابس بخلفية شفافة وقاعدة بيضاء للأقمشة الداكنة، أختام بنسخة معكوسة. **تباين النص يُفحص على الخلفية الحقيقية** ويُصحّح آليًا.
- **ملف الطباعة** (`pdf.ts`): CMYK + TrimBox/BleedBox + طبقات Spot حقيقية (CutContour / KissCut / Fold) بخطوط Vector (الأقواس منحنيات Bézier)، بدون مكتبات خارجية — تم التحقق من فتحه وعرضه بـ pdftoppm.
- **الملفات**: PDF الإنتاج، PNG بالدقة النهائية، معاينة JPG، مسار القص SVG بالمليمتر، قناع الأبيض، النسخة المعكوسة، **مصدر قابل للتعديل** (`.fcprint.json`) وبطاقة إنتاج JSON.
- **طبقات التشطيب** (فويل ذهبي/فضي، Spot UV، بارز/غائر): لوح فصل مستقل 100٪ أسود بنفس مقاس وموضع التصميم (PNG + PDF رمادي بنفس TrimBox) للعناصر المختارة (الشعار والعنوان / الشعار / العنوان / الاسم)، مع معاينة ملوّنة، وفحص أن النص لا يقل عن 8 نقاط (10 للبارز).
- **المعاينة الواقعية** (`mockup.ts`): من بكسلات التصميم نفسه — بطاقات على سطح، رول أب في معرض، كوب بالتفاف أسطواني، علبة ثلاثية الأبعاد، استيكرات، تيشيرت، كانفس، كتاب. مكتوب عليها «للعرض فقط».
- **الجودة بستة مستويات** (`qa.ts`): بصري، هوية، لغة، فني، طباعة، نشر — PASS / NEEDS_REVISION / BLOCKED / NOT_VERIFIED. لا PASS لما لم يُفحص. «جاهز للإنتاج» فقط بعد الاعتماد والتصدير وفتح الملف وبلا مشاكل.
- **الاعتماد والإصدارات**: بصمة SHA-256 للتصميم المعتمد؛ أي تعديل بعدها يلغي الاعتماد؛ 20 نسخة سابقة مع تراجع.
- **الإعلان**: «إنشاء إعلان للمنتج» يرسل المعاينة الواقعية للتصميم المعتمد إلى خط «أعمال منجزة» (شعار المطبعة الأصلي + رقما الفرعين يضيفهما النظام) ← طابور الموافقات. بدون أسعار أو وعود، واسم العميل فقط بموافقته.
- **فصل الهوية**: بيانات المطبعة داخل منتج عميل بدون موافقته = BLOCKED.

## حدود معروفة (قيد التطوير)
- **CMYK بملف عام مدمج** ما لم يُضبط ملف ICC للمطبعة ← «غير متحقق».
- **PDF/X غير مُنتَج** — يظهر «غير متحقق» إن طلبته المطبعة.
- **النص مرسوم داخل الصورة** بالدقة النهائية (يعادل Outlines) — غير قابل للتحرير داخل PDF؛ التعديل من المشروع.
- **طبقات التشطيب**: تُولّد آليًا (انظر أعلاه)، لكن الترحيل/التضييق (trap) حسب جهاز الفويل لا يُطبّق — يراجعه فني الإنتاج.
- **التغليف**: رفع Dieline يُحفظ لكن قراءته وتركيب التصميم عليه آليًا غير منفّذ بعد — يبقى معاينة فقط.
- **صور الذكاء الاصطناعي محدودة البكسلات** للمقاسات الكبيرة (يُبلَّغ عنها في فحص الدقة).
- **الكتب**: الغلاف وقوالب الصفحات فقط؛ محتوى الصفحات من العميل.
- المعاينات الواقعية مبسطة (ليست تصويرًا فوتوغرافيًا).
